# CYBER ARCADIA

هاب بازی آرکیدی نئونی، فارسی و راست‌چین؛ نسخه ایستا و قابل انتشار روی **GitHub Pages**.

## امکانات
- هشت کارت بازی و اجرای بازی‌های داخلی یا پیوند به بازی خارجی
- رابط راست‌چین واکنش‌گرا برای موبایل و دسکتاپ
- جست‌وجوی زنده بین بازی‌ها (کلید میانبر `/` و پاک‌کردن با `Esc`)
- جلوه‌های صوتی و موسیقی تولیدشده در مرورگر
- ذخیره رکوردها و تنظیمات در مرورگر بازیکن
- نشانگر وضعیت اتصال و پشتیبانی از کش آفلاین
- قابلیت نصب به‌صورت وب‌اپ (PWA) در مرورگرهای سازگار
- رعایت تنظیم کاهش حرکت سیستم، فوکوس صفحه‌کلید و پیوند پرش به محتوای اصلی
- مرکز فرماندهی محلی برای آمار، تحلیل ساده و پشتیبان‌گیری/بازیابی

## انتشار
در **Settings → Pages**، شاخه `main` و پوشه `/(root)` را انتخاب کنید.

سایت: https://arezosaleh040-wq.github.io/CYBER-ARCADIA/

پنل محلی: https://arezosaleh040-wq.github.io/CYBER-ARCADIA/admin/

## نصب و حالت آفلاین
سایت را یک بار با اینترنت باز کنید تا فایل‌های اصلی در Service Worker ذخیره شوند. سپس در مرورگرهای پشتیبانی‌شده می‌توانید آن را نصب کنید و بخش‌های کش‌شده را در حالت آفلاین باز کنید. بازی خارجی OpenFront و منابعی که هنوز کش نشده‌اند به اینترنت نیاز دارند.

## ذخیره‌سازی و حریم خصوصی
رکوردها در LocalStorage همان مرورگر ذخیره می‌شوند و به سرور ارسال نمی‌شوند. پاک‌شدن داده‌های مرورگر می‌تواند رکوردها را حذف کند؛ از پنل محلی پشتیبان بگیرید.

پنل مدیریت فقط داده‌های همان دستگاه را می‌بیند؛ احراز هویت مرکزی، کاربران مشترک یا جدول امتیازات جهانی وجود ندارد. GitHub Pages فقط فایل ایستا میزبانی می‌کند و PHP/MySQL یا بک‌اند اختصاصی اجرا نمی‌کند.

## توسعه و بررسی
فایل `index.html` را با یک وب‌سرور ایستا اجرا کنید. تست‌های خودکار در GitHub Actions سینتکس اسکریپت‌ها، وجود فایل‌های PWA، ساختار HTML، مسیر فایل‌های محلی و اتصال شناسه‌های DOM را بررسی می‌کنند.

هیچ کلید API، رمز عبور یا توکن خصوصی را در مخزن عمومی قرار ندهید.
